locked field - a field that cannot be modified
	> e.g. dsName

fixed field - a field that gets modified as a direct result of user's action
	and has no secondary action (i.e. date modified / name modified do not get updated)
	> e.g. vendor id, schemaVersion

source - a field that only gets modified as a direct result of user's action
	> user field (e.g. description)

dest - a field that can get modified as a direct result of user's action or
		can get modified from an alt source (e.g. usr field being modified / shts list being modified)
	> when modified by direct user action, acts like a source field
	> when modified by an alt source, only that source can un-modify (undo or apply)
	> needs flag for who modified and
	> needs flag for who can modify
	> dest field (e.g. name modified, last id)

indirect field - a field that ONLY gets modified as a indirect result of user's action
		gets modified from an alt source (e.g. usr field being modified / shts list being modified)
	> indirect field (e.g. date modified)

final field - a field that only gets updated due to a indirect or dest field (no other fields follow)
	> final field (e.g. none)
